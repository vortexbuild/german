# Deutsch

Ein eigenständiges **Nachschlagewerk und Trainingsmaterial** für die deutsche Sprache.
Ziel: von B1 zu sicherer, funktionaler Sprachbeherrschung auf B2/C1.

Aufgebaut zum Lesen und Verstehen — zuerst die Erklärung, dann die Tabelle, dann Beispiele.
Üben ist optional; das Nachschlagewerk selbst ist der Kern. Dieses Projekt ist
**vollständig auf Deutsch** (einzige Ausnahme: die Übersetzungsspalte in `vocab/vocab.csv`).

## Aufbau

| Pfad | Inhalt |
|------|--------|
| `grammar/` | Der Kern. Eine Datei pro Thema, in Reihenfolge — siehe `grammar/README.md` |
| `reference/` | Zum schnellen Nachschlagen: Verblisten, Präpositionen nach Kasus, Konnektoren, Partikeln |
| `vocab/vocab.csv` | Wortschatz: `deutsch,englisch,tags,hinzugefuegt` |
| `ROADMAP.md` | Die Niveaustufen A1–C1 und was jede Stufe verlangt |
| *(optionales Üben)* | `scripts/quiz.py` Karteikarten · `journal/` Schreibübungen |

## Verwendung

Lies `grammar/` von oben nach unten in der angegebenen Reihenfolge. Jede Datei steht für
sich: erst die Erklärung lesen, dann die Tabelle studieren, dann die Beispiele
durcharbeiten. Für schnelles Nachschlagen dient `reference/`. Neue Wörter trägst du in
`vocab/vocab.csv` ein.

Übungen und Tagebuch sind vorhanden, falls du sie nutzen möchtest, aber nicht verpflichtend.
