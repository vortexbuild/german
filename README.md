# German

A self-contained **reference and training material** for German, aimed at moving from
B1 to functional B2/C1 fluency. Built to be read and understood — explanation first,
then tables, then worked examples. Practice is optional; the reference is the point.

## Layout

| Path | What it is |
|------|-----------|
| `grammar/` | The core. One file per topic, ordered — see `grammar/README.md` |
| `reference/` | Quick-lookup material: verb lists, prepositions-by-case, connectors, particles |
| `vocab/vocab.csv` | Vocabulary store: `german,english,tags,added` |
| `ROADMAP.md` | CEFR levels A1→C1 and what each requires |
| *(optional practice)* | `scripts/quiz.py` flashcards · `journal/` writing practice |

## How to use it

Read `grammar/` top to bottom in the listed order. Each file stands alone: read the
explanation, study the table, work through the examples. Come back to `reference/` for
lookups. Add words you meet to `vocab/vocab.csv`.

Drills and journaling are there if you want them, but not required.
