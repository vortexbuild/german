# Plan / Lernplan

**Level:** B1 → solid **B2** (grammar). The last three topics reach into C1.
This covers only the **grammar** gap. The other half of B2 is **vocabulary breadth**
(~2500 → 4000+ words) — that comes from input, not this checklist.

No schedule, no daily routine. Work a topic whenever you sit down; when it feels done,
move on.

## Per topic — one unit of work

1. Read the `/en/` Lingolia page for the rule (+ the local note if one exists).
2. Read the `/de/` Lingolia page — for the examples. Read them aloud.
3. Do the free Lingolia exercise, or the drills in the local note.
4. Tick the topic below.
