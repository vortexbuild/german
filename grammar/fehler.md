# Fehlerheft (error log)

Die wichtigste eigene Datei im Projekt. Immer wenn eine Korrektur kommt (aus dem
Tagebuch, aus dem Unterricht, aus einem Gespräch), hier eintragen. Regelmäßig von oben
nach unten wiederholen — wiederkehrende Fehler markieren.

## Format

```
### JJJJ-MM-TT — kurzes Stichwort
- ✗ falsch:  <was ich geschrieben/gesagt habe>
- ✓ richtig: <die Korrektur>
- Regel:     <warum — welche Grammatik / welches Muster>
```

---

## Einträge

### 2026-08-28 — Beispiel (löschen, wenn der erste echte Fehler kommt)
- ✗ falsch:  Ich habe gegangen nach Hause.
- ✓ richtig: Ich bin nach Hause gegangen.
- Regel:     Bewegungsverben bilden das Perfekt mit *sein*; Partizip steht am Satzende.
