# External resources (curated links)

> 🇩🇪 Deutsch: [`../../de/referenz/links.md`](../../de/referenz/links.md)

See also: `abbreviations.md` — common abbreviations (z. B., bzw., d. h. …).

Rather than writing everything from scratch: proven explanations with examples and free
exercises. **Lingolia** is the main source (free to read; the extra exercises with an
answer key are Lingolia Plus / paid).

> **Important:** Lingolia renders the same page **differently** depending on the display
> language.
> - `/en/grammar/…` — more explanatory prose in English. Good for **first contact** with
>   a new rule. But: the example sentences are shortened and simplified, each line has an
>   English translation next to it (distraction), and there are occasional translation errors.
> - `/de/grammatik/…` — terser text, but **more and more natural example sentences**,
>   no translation noise. Better for the examples and as reading practice.
>
> **Recommendation:** learning a rule for the first time → `/en/`. Examples and review →
> always `/de/`. The links below are `/en/`; the `/de/` variant often has a different
> path (e.g. `/de/grammatik/nomen/deklination` instead of
> `/en/grammar/nouns-and-articles/declension`).
